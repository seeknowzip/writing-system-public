# 표현 복원

어색한 말을 지운 뒤 원문에 있는 정보와 행위자가 잘 드러나도록 고친다. 다음 항목은 편집 판단 지침이며, 외부 원문을 그대로 재배포한 전후 예시나 성능 검증 자료가 아니다.

## 0. 보존 범위와 선택적 글 참고

원문의 사실·조건·확신·관점을 먼저 잠근다. 원문에 없는 주체나 사례는 만들지 않는다. 어휘는 원문의 용어, 사용자가 지정한 용어 순으로 따른다. 전문어가 불확실하면 이용 가능한 사전·공식 문서에서 해당 용례만 확인하고 확인 범위를 기록한다. 조회 실패는 틀린 말이라는 증거가 아니다.

사용자가 자기 글을 참고하라고 요청했다면 [개인화 절차](personalization.md)를 따른다. 샘플이 없어도 모든 기본 교정 절차를 수행한다. 샘플의 사건·숫자·인물은 새 글의 사실 근거가 아니다.

## 1. 통용어

독자가 쓰는 용어를 설명용 조어로 바꾸지 않는다. 독자 수준이 미정이면 원문의 수준을 유지한다. 초보자를 위한 풀이도 필요할 때 첫 등장에만 붙인다.

## 2. 단어 결합

주체·행동·대상의 관계가 문법적으로 맞는지 본다. 단어 하나의 사용 빈도만으로 행동을 다른 행동으로 교환하지 않는다. 뜻이 불확실하면 후보와 확인할 점을 반환한다.

## 3. 동사와 행위자

명사구와 피동이 행동을 가리면 원문의 동사와 행위자를 되살린다. 피동 자체는 오류가 아니다. 책임 주체를 새로 단정하거나 진행 중인 일을 완료형으로 바꾸지 않는다.

## 4. 귀속

누구의 관측·해석·기대인지 유지한다. 발언자가 없는 문장에 전문가나 고객을 만들어 붙이지 않는다. 전망을 결과로 바꾸지 않는다.

## 5. 구체성

막연한 평가 대신 원문에 이미 있는 행동·조건·결과를 쓴다. 구체 자료가 없으면 확인 항목으로 남긴다. 설명용 가상 예시는 사용자가 허용한 경우에만 만들고 실제 사례와 분리한다.

## 6. 과압축

앞뒤를 읽어도 누가 무엇을 했는지 알 수 없을 때만 보존 목록에서 생략된 관계를 복원한다. 짧은 문장과 명사형 제목을 길이 때문에 늘리지 않는다. 원문에 없는 마찰이나 판단을 넣지 않는다.

## 7. 과설명

이미 전달한 결론을 다시 풀이하는 문장, 독자에게 불필요한 용어 설명을 줄인다. 조건·예외와 의도적인 반복은 남긴다.

## 8. 교정하지 않을 것

격식을 임의로 높이지 않는다. 종결어미의 반복만으로 변주하지 않는다. 강조 부사, 더 강한 확신, 새로운 장점을 추가하지 않는다. 자연스러운 원문은 그대로 둔다.

## 9. 프로젝트 목소리

반말·존댓말, 브랜드 용어, 이모지 등은 사용자와 프로젝트의 선택이다. 이 지침이 보편적인 페르소나를 정하지 않는다.
