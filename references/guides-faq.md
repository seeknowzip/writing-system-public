# Guides and FAQ information roles

## Guide roles

1. 이 문서가 해결하는 사용자 질문
2. 시작 전 알아야 할 영향·자격·준비물
3. 실제 진행 순서
4. 각 단계의 완료 결과
5. 예외·취소·복구·비용·시점
6. 해결되지 않을 때 다음 채널

## Delivery slots

- `web + help_article`: 검색 가능한 제목, 즉답 또는 준비 조건, 본문, 다음 도움 경로.
- 실제 앱 화면의 짧은 안내라면 `app + ui_copy`로 바꾸고 `product-ui.md`를 사용한다.

## Draft check

- 첫 단락에서 대상 기능과 결과를 정확히 정의했는가
- 번호 순서가 화면 메뉴가 아니라 사용자 행동 순서인가
- 버튼을 누른 뒤 무엇이 완료되는지 쓰였는가
- 비용·취소·복구·예외·처리 시간을 빠뜨리지 않았는가
- 답을 찾지 못한 사용자의 다음 채널이 있는가
