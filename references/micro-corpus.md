# 짧은 문구의 정보 역할

아래는 공개본을 위해 만든 합성 예시다. 실서비스 문구나 효과가 입증된 카피가 아니다.

| 상황 | 합성 문구 | 확인할 점 |
|---|---|---|
| 파일 선택이 필요한 상태 | 비교할 문서 선택 | 누르면 무엇을 고르는가 |
| 임시 저장 완료 | 초안을 저장했어요. | 실제 저장 결과가 확인됐는가 |
| 재시도 안내 | 연결을 확인하고 다시 시도해 주세요. | 실제 원인과 맞는 안내인가 |

짧게 만드는 것보다 현재 상태와 다음 행동을 정확히 전달하는 것이 먼저다. 예시 문구를 실제 제품 상태 확인 없이 붙이지 않는다.
