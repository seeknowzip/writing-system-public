# Landing and marketing information roles

## Required roles

1. 독자가 현재 느끼는 긴장, 욕구, 또는 해결할 과업
2. 한 문장 제안: 무엇이 어떻게 달라지는가
3. 포지셔닝: 현재 방식이나 대안과 비교해 왜 이 선택이 중요한가
4. 작동 방식 또는 제품 범위
5. 검증 가능한 근거와 조건
6. 다음 행동 하나

## Delivery slots

- `web + landing_page`: 페이지 제목·리드·근거 구획·CTA를 분리한다.
- 다른 채널 조합이 필요하면 brief의 `channel`과 `delivery_format`을 먼저 바꾸고 해당
  전달 형식의 슬롯을 확인한다. 장르만 보고 이메일 제목이나 앱 알림 구조를 추측하지 않는다.

상위 약속과 기능 목록을 같은 문장에 넣지 않는다. 근거가 없는 경우 수치 자리를
그럴듯한 형용사로 채우지 말고 작동 방식을 더 구체적으로 쓴다.

## Draft check

- 첫 화면만 읽어도 대상, 변화, 다음 행동이 보이는가
- 회사나 제품명을 바꿔도 같은 제안이 성립하지 않는가
- 차별점이 수식어가 아니라 사실·작동 방식·선택 기준에 연결되는가
- 두 번째 구획에서 작동 방식이 구체화되는가
- 근거가 회사 자체 주장인지 독립 사실인지 구분했는가
- CTA가 구획마다 늘어나지 않고 하나의 행동으로 수렴하는가
- 헤드라인의 의미를 리드와 카드가 그대로 반복하지 않는가
