# 선택적으로 내가 쓴 글 참고하기

개인화는 별도 모델 학습이나 자동 페르소나 복제가 아니다. 사용자가 이번 작업에 지정한 글에서 표현 선택을 참고하는 절차다. 글이 없어도 기본 작성·재작성은 동일하게 동작한다.

1. 사용자가 지정한 자기 글만 읽는다. `local/author-samples/`는 권장 보관 위치이며 폴더가 있다는 이유로 자동 수집하지 않는다. 다른 폴더나 Notion을 탐색하지 않는다.
2. 존댓말 수준, 자주 쓰는 용어, 설명의 구체성, 판단을 드러내는 방식을 살핀다. 소수 샘플에서 성격·신념·고정 문체를 단정하지 않는다.
3. 이번 글에 적용할 표현 선택과 근거 위치를 짧게 기록한다. 사용자 요청·현재 글의 사실·격식이 샘플보다 우선한다. 애매한 특성은 적용하지 않는다.
4. 샘플의 고유 문장·일화·고객·금액을 새 글로 옮기지 않는다. 실제 인용이나 사례 재사용은 별도의 명시 요청과 사실 근거가 필요하다.
5. 원문과 결과를 대조해 확신·의미·목소리가 달라지지 않았는지 확인한다. 적용한 선택과 적용하지 않은 선택을 구분한다.

`local/`은 Git에서 무시된다. 사용자의 에이전트가 해당 글을 읽으면 이용 중인 모델 서비스로 내용이 전달될 수 있으므로 오프라인 처리나 비밀 보장을 의미하지 않는다. 개인 샘플을 공개 예제나 테스트로 복사하지 않는다.
