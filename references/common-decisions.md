# 정보 구성 판단

이 항목은 공개본의 작성 지침이다. 특정 기업의 성과나 원문 품질을 입증하지 않는다.

- 독자가 해결하려는 질문을 먼저 정하고 해당 질문에 필요한 사실을 고른다.
- 혜택을 말할 때 적용 조건과 예외를 가까이 둔다.
- 순서가 있는 업무는 행동과 완료 결과를 연결한다.
- 제목·리드·본문·다음 행동이 같은 결론을 반복하지 않게 한다.
- 에디토리얼에서는 실제 선택과 판단이 바뀐 이유를 남긴다. 장면을 지어내지 않는다.
- 상태가 다르면 구별한다. 신청과 승인, 저장과 발행은 같은 결과가 아니다.
- 참고 글의 구조를 관찰해도 사실·고유 표현·비유는 복사하지 않는다.
- 공식 발행 여부와 문안의 적합성을 별도로 판단한다.
