# Repair playbook

초안이 약할 때 문체 통일을 이유로 전면 재작성하지 않는다. 다만 `FT12`처럼 제안과
크리에이티브 방향 자체가 교체 가능하면 국소 윤문으로 고치지 말고 해당 설득 구획을
방향부터 다시 쓴다. 모든 수정 뒤 사실·보호 문자열을 다시 검사한다.

## Structure repairs

### FT01, FT02: 약속과 구획 역할

- 제목: 대상 또는 변화 하나
- 리드: 왜 지금 읽어야 하는지
- 본문 첫 구획: 실제 작동 방식 또는 근거
- CTA: 사용자가 할 행동
- 네 요소가 같은 뜻이면 가장 구체적인 문장 하나만 남기고 나머지 역할을 바꾼다.
- 같은 명사를 썼다는 이유만으로 지우지 않는다. 본문이 작동 방식·조건·근거·예외를
  더하면 제목의 결론을 뒷받침하는 별도 역할이다.

### FT03, FT07: 조건과 예외

- 혜택 문장마다 `누구에게`, `언제`, `무엇을 해야`, `무엇이 제외되는지`를 확인한다.
- 취소·비용·되돌리기 조건은 첫 등장과 같은 구획으로 옮긴다.
- 조건이 확정되지 않았으면 단정 대신 확인 경로를 쓴다.

### FT04, FT06: 탐색과 절차

- 메뉴나 부서명을 독자의 질문·상황으로 다시 묶는다.
- 각 단계는 `행동 → 시스템 반응 → 완료 상태 → 예외` 중 필요한 것만 가진다.
- 한 단계에 주체가 둘이면 분리한다.

### FT05: 즉답

- FAQ: 첫 문장에 가능·불가·조건부를 쓴다.
- 공지: 첫 화면에 변화·영향 대상·시점·사용자 행동을 쓴다.
- 보안: 현재 영향·해제 행동·실패 대안을 앞세운다.

### FT08: 주체

- 모든 동사에 실제 행위자를 붙여 읽는다.
- 회사가 처리하는 일, 사용자가 해야 하는 일, 외부 업체가 결정하는 일을 구획으로 나눈다.
- 수동태가 책임을 감추면 주체를 복원한다.

### FT09: 증거 수준

- 직접 확인한 사실: `~했다`, `~이다`
- 회사 자체 관측: `회사 집계 기준`, `페이지가 제시한 수치`
- 해석: `~로 해석했다`, `~로 봤다`
- 전망·기대: `~할 계획이다`, `~를 기대한다`
- 독립 검증이 없으면 최상급과 인과를 제거한다.

### FT10, FT11: 표면 장치와 빈 근거

- 이모지·감탄·말장난을 지운 뒤에도 정보 순서가 작동하는지 본다.
- 접근하지 못한 화면이나 동적 조건은 만들지 말고 확인 항목으로 반환한다.

## Creative quality repairs

### FT12: 교체 가능한 제안

- `독자의 긴장 → 원하는 변화 → 사실 기반 차별점 → 기억할 한 가지`를 다시 적는다.
- 제품명을 지운 문장이 경쟁사에도 그대로 맞으면 제목과 리드를 폐기한다.
- 차별점을 증명할 사실이 없으면 우월함을 만들지 말고 구체적 사용 장면이나 작동 방식으로
  범위를 낮춘다.
- 제목만 화려하게 고치지 않는다. 제안이 바뀌면 근거 구획과 CTA까지 같은 방향인지 본다.

### FT13: 조립된 리듬

- 병렬 항목이 서로 다른 사실이면 유지하고, 같은 의미의 형용사 변주만 지운다.
- 연속 문장의 길이·주어·종결을 소리 내어 읽고, 모두 같은 틀일 때만 필요한 차이를 만든다.
- 대구·반복·압축은 브랜드와 판매 장르의 기능일 수 있다. 형식 이름만으로 제거하지 않는다.

### FT12~FT14 공통: 채우기

- 빼기 뒤 빈자리는 `register-restoration.md`(통용어·연어·동사와 행위자·귀속·구체성)로 채운다. 원문에 재료가 없으면 채우지 않고 확인 항목으로 남긴다.

### FT14: 인간적 판단 부재

- 독자가 실제로 맞닥뜨리는 순간, 선택, 실패, 질문 중 근거가 있는 하나를 진입점으로 고른다.
- “중요하다”, “도움이 된다” 같은 합의 가능한 결론 대신 무엇을 먼저 보거나 버릴지 판단한다.
- 꾸며낸 인용·감정·장면은 금지한다. 근거가 없으면 관찰 가능한 행동과 선택만 쓴다.

### FT15~FT17 (candidate)

- FT15 어휘 우회: `register-restoration.md` §1. 원문이 쓴 어휘 수준을 넘어 풀지 않는다.
- FT16 과압축: §6. 보존 목록 안의 `행동→마찰→판단`만 복원한다.
- FT17 과설명: §7. 잡초·중복·사전식 풀이를 지우되 §8의 반대 방향(격식 상승·변주 강요·강조 부사)으로 가지 않는다.

## Recheck

1. 고친 구간이 독자의 질문에 더 빨리 답하는가
2. 조건과 예외가 관련 약속 가까이에 있는가
3. 사실·수치·날짜·고유명사·보호 문자열이 바뀌지 않았는가
4. 새로운 성과·원인·감정·긴급감을 만들지 않았는가
5. 회사명을 바꿔도 성립하는 제안이나 무난한 당위문이 남지 않았는가
6. 다른 문단까지 문체 통일을 이유로 덮어쓰지 않았는가
