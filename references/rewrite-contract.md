# Rewrite contract

`rewrite`는 원문의 사실·의도·화자 목소리를 보존하며 어색한 표현을 고친다.
문서 구조는 독해 실패가 확인된 구획만 수리한다.

## 입력

필수 입력은 `source_text`다. `voice`, `protected_strings`, `facts`, `audience_familiarity`,
`adapter`는 선택이다. `audience_familiarity`는 `novice | practitioner | expert | unknown`이며,
없으면 원문의 어휘 수준을 유지한다. 전문어 하나가 있다고 모든 개념을 아는 독자로 추정하지 않는다.
`genre`·`channel`·`positioning`·패킷 선택이나 전체 brief를 요구하지 않는다.

`high-stakes`에서는 원문과 사용자 자료에서 축약 brief를 만든다: `facts`, `protected_strings`,
`voice`, `human_review`, 해당하는 `compliance_triggers`와 `compliance_source`.
`facts[].source`에는 원문 위치를 기록하되 외부 사실 검증을 했다고 표시하지 않는다.
사람 검토 항목을 `human_review`에 명시하고 `release-contract.md`를 따른다.
승인 근거가 없으면 만들어 넣지 않고 `internal_review_only`와 미확인 항목으로 남긴다.

## 절차

1. **보존 목록**: 사실·수치·조건·예외·인과·고유명사·인용·소유 표현·확신 수준·화자 관점·의도적
   수사를 원문 위치와 함께 잠근다. 조건·판단 문장을 상투구로 지우지 않는다.
2. **단서 읽기**: 화자·독자·도메인은 원문과 사용자 힌트에서 읽는다. voice가 없으면 원문 격식을 유지한다.
3. **진단**: `failure-taxonomy.md`와 `surface-tells.md`로 실제 읽기 문제를 지목한다. 문제 없는 문장은
   무개입이다. 문장마다 FT12~FT17·surface 항목을 대조하고, 원문·판단·근거를 `rewrite-validation.md`의 v2 진단에 남긴다.
   사람 글의 3분의 1 넘게 지목했다면 각 근거를 재검토한다. 비율 자체는 통과 기준이 아니다.
   "더 매끄럽게"만으로는 이유가 되지 않는다. 문장 자체가 자연스러워도 앞뒤 주제와 연결되지 않는
   구간은 관련성 확인 항목으로 남긴다. 종결어미만 맞춘 것을 문맥 해결로 판정하지 않는다.
4. **재작성**: 지목한 span에서 빼기와 `register-restoration.md`의 채우기를 수행한다.
   새 사실이 필요한 부분은 추측하지 않고 확인 항목으로 돌린다. 지목하지 않은 문장은 보존한다.
5. **연속성**: 고친 문장의 앞뒤를 읽고 의미·목소리가 이어지는지 확인한다. 순서·연결 변경이 필요하면
   해당 문단의 진단에 근거를 남긴다. 결과를 통과시키려고 사후에 근거 없는 지목을 추가하지 않는다.
6. **구조 판단**: 문장 수리 뒤에도 아래 P3 게이트가 남을 때만 해당 구획을 고친다. 전체 재배열·CTA
   신설·장르 템플릿 적용은 명시 요청이 있어야 한다. 원문 사실을 삭제해야 풀리는 문제는 제안으로 반환한다.
7. **재검증**: `rewrite-validation.md`의 기계 검사 후 보존 목록을 의미 단위로 대조한다. 두 문단 이상인
   글이나 `high-stakes`에서는 별도 서브에이전트가 원문·첫 검증 통과본·최종본을 대조하여 사실·행위자·시점·
   조건·예외·확신·신규 명제를 보고한다. 도구가 없으면 자기 재검토임을 표시하고 독립 검토 완료로 기록하지 않는다.
   단독 평가자의 조건·확신 이동 지적도 미해결이면 확인 항목이다. 검증 오류가 남으면 최종본으로 전달하지 않는다.

### P3 게이트

- 첫 화면에 독자의 답이 없다 (FT01/FT05)
- 제목·리드·본문이 같은 결론을 반복한다 (FT02 — 4부 역할 대조)
- 조건·예외가 관련 약속과 다른 구획에 있다 (FT03/FT07)
- 압축으로 행동과 판단의 연결을 따라갈 수 없다 (FT16)

## 결과

1. 재작성한 문안
2. 손댄 span과 이유, `restored_terms[]` — 후속 humanize에 `protected_strings`로 전달
3. 미확정 사실·용어·문맥 관련성·구조 제안·사람 검토 항목
4. 기계 검사와 의미 대조 결과, 산출물에만 있는 명제와 `facts[n]` 또는 `UNVERIFIED`

`local/usage-log.md`에는 경로·복원 용어·필요했던 조회·사람이 되돌린 구간을 기록한다.
미해결 확인 항목을 문안 밖에 전달하되 사람이 판정하기 전까지 해결됐다고 표시하지 않는다.
