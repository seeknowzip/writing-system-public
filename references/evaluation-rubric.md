# Evaluation rubric

각 항목을 0~2점으로 평가한다. 총점보다 **0점 항목과 사람 수정량**을 먼저 본다.

| 항목 | 0 | 1 | 2 |
|---|---|---|---|
| 사실 충실도 | 사실 추가·변형 | 모호하거나 검토 필요 | brief와 일치 |
| 독자·상황 적합성 | 회사 중심 | 일부 맞음 | 첫 구획부터 과업 중심 |
| 정보 구조 | 누락·중복 | 읽히나 재배열 필요 | 장르 역할과 순서가 선명 |
| 구체성·증거 | 추상 주장 | 일부 작동 방식 | 약속과 근거·조건 연결 |
| 관점·차별성 | 이름을 바꿔도 성립 | 방향은 있으나 일반적 | 독자 긴장과 사실 기반 선택 이유가 선명 |
| 인간적 구체성 | 장면·판단 없는 일반론 | 일부 구체적이나 조립감 남음 | 실제 순간·선택·판단이 자연스럽게 이어짐 |
| 행동 가능성 | 다음 행동 불명 | CTA 있으나 조건 분산 | 행동·완료·예외 명확 |
| 자연스러운 한국어 | 번역투·기계 반복 지배 | 국소 수정 필요 | 어조·리듬이 맥락에 맞음 |
| voice 보존 | 위반 | 경계 사례 | 프로젝트 규칙 준수 |
| 실사용 준비도 | 대폭 재작성 | 편집 후 사용 | 사실 확인 외 바로 사용 |

## Comparison protocol

- 두 스킬에 같은 fresh brief와 같은 사실 원장을 준다.
- 연구 원문이나 기대 답안을 brief에 넣지 않는다.
- 결과의 스킬 이름을 가린 뒤 rubric으로 평가한다.
- validator 실패는 해당 항목 0점이며 자연스러움 점수로 상쇄하지 않는다.
- `landing`, `marketing`, `editorial`, `social`은 관점·차별성과 인간적 구체성을 모두
  적용한다. 다른 장르는 매력적인 수사를 강요하지 않고 현재 상황의 구체성과 판단만 본다.
- 필요한 사람 수정은 `없음 | 국소 | 구조 재편 | 전면 재작성`으로 별도 기록한다.
- 세 개 이상의 서로 다른 장르로 평가한다. UI 한 줄만으로 장문 성능을 결론내리지 않는다.
